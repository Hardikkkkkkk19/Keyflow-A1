# KEYFLOW ⌨️

**AI-powered typing performance platform for speed, accuracy, coding skills, and competitive progression.**

[Live Demo] • [GitHub]

---

## ✨ Features

| Feature | Description |
|---|---|
| ⌨️ Typing Practice | Real-time speed and accuracy training |
| 💻 Code Practice | Practice real-world programming syntax |
| 🤖 AI Coach | Personalized feedback using typing telemetry |
| 📊 Analytics | Track WPM, accuracy, sessions and progress |
| 🏆 Leaderboard | Compete globally with other typists |
| 🎯 Challenges | Complete goals and earn XP |
| 🔥 Streaks | Build consistent daily practice |
| 🎨 Virtual Keyboard | Finger mapping and real-time key feedback |
| 🔊 Typing Sounds | Multiple keyboard sound profiles |

## 🛠️ Tech Stack

React • Vite • JavaScript • Supabase • Gemini AI • Framer Motion • Recharts
